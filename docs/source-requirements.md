# Source Requirements

This package was derived from the two provided source documents:

1. Hackathon Content Guide.docx
2. HackwithHyderabad 3.0 Problem Statament.docx

Important source-derived constraints:
- Hindsight is required.
- Memory must be central to the project's value.
- The project should solve a real problem.
- The demo should show improvement over time.
- Keep the scope tight.
- Use realistic data.
- The incident response use case is explicitly listed as an example.
- Judging weights: Innovation 30%, Hindsight Memory 25%, Technical Implementation 20%, User Experience 15%, Real-world Impact 10%.
- Submission requires a clean GitHub repository, demo video, live demo, content deliverables, and explanation of Hindsight usage.
